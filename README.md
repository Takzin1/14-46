# 14:46 — 高台へ

東日本大震災の教訓をもとにした、ブラウザで遊べる3Dサバイバルアクション型の**防災体験ゲーム（vertical slice／試作版）**です。
舞台は**架空の東北沿岸の町「潮凪町（しおなぎちょう）」**。強い揺れのあと、海が静かに見えても高台へ避難できるかを体験し、最後に自分の判断を振り返ります。

> **大切な注意**
> - 実在の被災地・地形・建物・人物、個人の被災経験を再現したものではありません。
> - 津波の表現は**演出用の簡易モデル**であり、科学的な浸水シミュレーションではありません。
> - 防災の専門家による検証は**受けていません**。教育効果や避難シミュレーションの精度は保証しません。
> - 実際の避難は、お住まいの自治体のハザードマップ・避難計画・公的な情報に従ってください。
> - このリポジトリの内容は**公開・SNS投稿していません**（ユーザーの明示的な許可があるまで行いません）。

## 史実と創作の区別

| 区分 | 内容 |
|---|---|
| **確認できる史実**（出典：気象庁） | 2011年3月11日14時46分に「平成23年（2011年）東北地方太平洋沖地震」が発生（M9.0）。14時49分、気象庁が岩手・宮城・福島に津波警報（大津波）を発表。第1報の予想は実際を大きく下回った |

ゲーム内では「史実と創作・出典」画面でこの区別を表示しています。詳しい出典は [CREDITS.md](CREDITS.md)。

### ゲームの流れ

1. **プロローグ**（商店街）— 14:45、買い物の途中。
2. **地震（14:46）**— 揺れの間は移動しにくくなります。頭を守ってしゃがみ（身を守る）、自動販売機・看板・ブロック塀・電柱など**倒れやすい物から離れる**。看板・自販機の転倒、瓦の落下が起こります。
3. **避難** — 揺れがおさまったら、すぐに高い場所へ。緑の避難標識・海抜表示・地図が手がかりです。
   - ルートA：坂道を上って高台の「潮凪台公園」（指定緊急避難場所・架空）
   - ルートB：近道の階段 — 地震で倒れた電柱にふさがれていて通れない
   - ルートC：津波避難ビル「潮凪町民センター」の外階段から屋上へ
   - 寄り道の誘惑：防潮堤から海を見に行く／駐車場の車で逃げる（渋滞）／店主や釣り人に声をかける
4. **安全な場所で** — 「さらに高い場所（潮凪神社）」へ移動できます。水が引いたあと「家に戻るか」を選びます。
5. **振り返り** — 点数はつけず、行動ごとに ◎／△／✕ と理由・公的資料の出典を表示します。行動の記録（ゲーム内時刻つき）も残ります。
6. **再挑戦** — 「揺れの直前から」または「最初から」。

避難が間に合わなかった場合は、**水が届く前に画面が暗転**し、「避難が間に合いませんでした（この先の描写はありません）」という非グラフィックな画面に切り替わります。人が被害を受ける描写はありません。

## 設計方針と実装の対応

| 原則 | 実装 |
|---|---|
| 「津波を見てから走れば逃げ切れる」という誤解を生まない | 浸水の前線は時速約32km（9 m/s）で進み、プレイヤーの全力疾走（5.6 m/s）より速い。町の中で水が見えてから坂道へ走っても間に合わない（テストで確認） |
| 揺れのあと速やかに高台へ避難する行動を中心にする | 揺れがおさまった瞬間から避難開始までの時間を記録し、振り返りで評価。防潮堤に上ると「海は静かに見える……でも安全のしるしではない」と表示 |
| 被災者の死亡・苦痛をスコア化・娯楽化しない | スコア・点数・ランキングなし。失敗時は水が届く前に暗転。NPCは水が近づく前に画面から外れる |
| 実在の犠牲者・場所を特定できる再現をしない | 架空の町・架空の人物・架空の地名のみ |
| 現実の警報と誤認されるサイレンや通知を使わない | 音はすべてWeb Audioの合成（低音の揺れ・波・足音・UI音）。サイレン、緊急地震速報の報知音、防災無線のチャイムは不使用。町内放送は**文字のみ**で「（ゲーム内の架空の町内放送）」と明記。OS通知は使わない |
| 公的資料を参照して避難原則を説明する | 気象庁・内閣府・仙台市の資料の要約と出典URLを、振り返り画面と「史実と創作・出典」画面に表示 |
| 専門家の検証前に効果・精度を保証しない | タイトル・注意画面・振り返り・README・動画のエンドカードに明記 |
| 内容注意・演出強度の軽減 | 開始前に内容注意を表示し、演出強度（標準／軽減／最小）をその場で選べる。最小ではカメラの揺れ・画面効果・落下物の動きをなくし、揺れは文字のメーターで表示、水は簡略表示、暗転のタイミングも早める |

## 技術構成

- **Vite + TypeScript + Three.js**（`three@0.170`）
- **Rapier**（`@dimforge/rapier3d-compat@0.14`）
  - プレイヤー：`KinematicCharacterController`（カプセル、坂道44°まで、段差0.35mまで自動で上る）
  - 地形：三角形メッシュのコライダー、建物・防潮堤・階段：直方体コライダー、落下する瓦：動的剛体
  - 三人称カメラ：Rapierのレイキャスト（5本）で壁にめり込まないよう手前に寄せる。見えない柵・階段は衝突グループでカメラ判定から除外
- **glTF**：キャラクターと車はオリジナルの `.glb`（`npm run assets` で `scripts/build-assets.mjs` から生成）を `GLTFLoader` で読み込み。ノード名（Hips/ArmL/LegR…）を使って手足を動かす。読み込みに失敗しても代替形状で遊べる
- **モバイル**：タッチのスティック・視点ドラッグ・ボタン、縦画面では視野角を広げる、`pointer: coarse` で自動判定（設定で常時表示／非表示も可）
- **設定**：演出強度・音量・カメラ感度・上下反転・タッチ操作・画質（影の有無）・FPS表示。`localStorage` に保存（使えない環境でも動作）

```
src/
  main.ts          起動、ループ、テスト・キャプチャ用API（window.__game）
  game.ts          進行（プロローグ→地震→避難→安全→振り返り）、判定、記録
  content.ts       画面に出る文章・史実・原則・出典（監査しやすいよう一か所に集約）
  review.ts        判断の振り返り（点数なし）
  player.ts        キャラクター制御・手足のアニメーション
  camera.ts        三人称カメラと衝突判定
  input.ts         キーボード・マウス・タッチ
  audio.ts         合成音（警報音なし）
  npc.ts           店主・釣り人・近所の人
  ui.ts            画面・HUD・ハザードマップ
  world/layout.ts  架空の町の配置と地形の高さ
  world/terrain.ts 地形メッシュとコライダー
  world/city.ts    家・商店・避難ビル・防潮堤・標識・倒れる物
  world/water.ts   海と、演出用の簡易な浸水表現
```

### 津波の表現について（簡易モデル）

`src/world/water.ts`：海は揺れのあとも**静かなまま（引き潮もない）**。決めた時刻になると沖に白い線が見え、海面が上がり、防潮堤を越えた水の前線が一定の速さで内陸へ進み、水位が一定の高さ（ゲーム内の海抜9.5m）まで上がります。地形・建物による流れ、引き波、漂流物などは一切計算していません。ゲームの判断を体験するための**演出**です。

## テスト

```bash
npx playwright test               # すべて（ビルド→プレビューサーバーは自動起動）
npx playwright test --project=desktop
npx playwright test --project=mobile
```

| 分類 | 内容 |
|---|---|
| ビルド | `dist` が生成され、エラーなく起動し、glTF 2点が読み込まれる |
| 内容注意 | 注意・創作の明示・免責が表示され、選んだ演出強度が保存される／出典URLが公的機関のものだけ |
| 操作 | 歩く・走る・身を守る・地図・一時停止（キーボード）、声かけでNPCが避難を始める |
| カメラ衝突判定 | 開けた場所では衝突なし／避難ビルの壁を背にすると手前に寄り、壁の中に入らない／周囲12方向でカメラが固体の中に入らない |
| ステージ到達 | 坂道ルートで高台 → 神社 → 「戻らない」→ 振り返り／避難ビルの外階段で屋上（海抜17m） |
| 避難判定 | 海を見に行くと失敗し、水が届く**前**に結果画面に切り替わる／水が見えてから走ると間に合わない／車を選ぶと渋滞で約30秒失う／近道はふさがれている／再挑戦で倒れた物が元に戻る／演出強度「最小」でカメラの揺れがゼロ |
| モバイル | Pixel 7 相当（縦画面・タッチ）でスティック移動・視点ドラッグ・身を守る・地図、画面が横にはみ出さない |
| FPS | リアルタイム描画でFPSを計測（下記） |
| 動画 | 15秒・30秒のMP4が 1080x1920・H.264・AAC・30fps・指定の長さで、最後までデコードできる |

テストはゲーム内時間を決まった刻みで進める `?capture=1` モード（`window.__game.advance()`）を使うので、PCの速さに左右されません。

### FPSについて

この作業環境のテストは GPU のないヘッドレス Chromium（SwiftShader によるCPUでのソフトウェア描画）で動かしているため、数値は実機より大幅に低くなります。**実機のGPU（PC・スマートフォン）での性能はまだ計測していません。** 画質「低」は影とアンチエイリアスを切り、描画解像度を1倍にします（アンチエイリアスの切り替えは再読み込み後に反映）。

## 検証結果（2026-11-03、この作業環境）

- `npx playwright test`：**24件すべて合格**（desktop 22件・mobile 2件）
- FPS（SwiftShader・1280x720）：rAFループ 約25〜33fps。描画完了まで同期させた1フレームの実コストは 画質「高」約0.5秒／「低」約0.2〜0.33秒（＝ソフトウェア描画では2〜5fps相当）。rAFの数値はGPU処理の完了を待たないため、実際の描画性能の指標にはなりません
- 動画：`media/takadai_15s_1080x1920.mp4`（15.04秒）、`media/takadai_30s_1080x1920.mp4`（30.04秒）。どちらも 1080x1920・H.264(High)・30fps・AAC。FFmpegで全フレームのデコード、Chromiumの`<video>`で再生を確認

## 動画（実プレイ画面）

```bash
npm run build
npm run video      # = node scripts/capture-video.mjs && bash scripts/edit-video.sh
```

1. `scripts/capture-video.mjs`：実際のゲームを Playwright で**自動操作**し、1フレームずつ（30fps）1080x1920 で保存。ゲーム内の放送文や操作ヒントは、現実の警報と誤認されないよう動画では非表示にしています（時計・目標表示・「津波の表現は簡易モデル」の注記は残しています）。
2. `scripts/edit-video.sh`：FFmpegで場面を切り出し、落ち着いたテロップ・「実際のゲームプレイ画面（自動操作・架空の町）」の表示・エンドカード（架空であること、簡易モデルであること、自治体の情報に従うこと）を入れて書き出し。

| ファイル | 長さ | 構成 |
|---|---|---|
| `media/takadai_15s_1080x1920.mp4` | 15秒 | 揺れて身を守る → 静かな海 → 高台へ走る → 高台から見る沖の白い線 → エンドカード |
| `media/takadai_30s_1080x1920.mp4` | 30秒 | 商店街 → 揺れ（自販機・看板の転倒）→ 静かな海 → 近所の人と坂道を上る → 高台 → エンドカード |

テーマは「海が静かでも避難が必要」。被害を面白がる表現、浸水した町のアップ、扇情的なテロップは入れていません。**動画は公開・投稿していません。**
